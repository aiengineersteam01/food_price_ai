ABOUT THE SYSTEM

About Food Price AI

Food Price AI is an artificial intelligence based food commodity price forecasting system. It uses historical market price information to estimate future commodity prices.

The system combines traditional machine learning algorithms with deep learning approaches. This allows users to compare different modeling techniques and understand how each model performs.

Why Multiple Models?

No single forecasting algorithm is guaranteed to perform best for every situation. By providing multiple models, the system makes it possible to compare their predictions and performance using standardized evaluation metrics.

Models Used

  • Linear Regression
  • Random Forest
  • Gradient Boosting
  • Stacking Regression
  • Neural Network
  • LSTM
  • Round 1 Linear Regression
  • Round 1 Random Forest
